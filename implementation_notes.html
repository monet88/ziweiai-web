1. Unspecified & Implicit Decisions

  • Acoustic Asset Generation (PCM 44.1kHz): Do hệ thống không phụ thuộc vào network CDN bên thứ 3 cho hiệu ứng âm thanh cốt lõi, âm thanh xóc ống thẻ Quan Thánh (stick_shake.wav) và tiếng lật bài Tarot (card_flip.wav) được tổng hợp trực tiếp bằng Python script thuật toán âm học vật lý, đảm bảo kích thước siêu nhẹ (<100KB) và độ trễ phát 0ms (instant latency).
  • Web Audio Web API vs Audio Files: Trên nền tảng Web SvelteKit, thay vì tải các tệp tĩnh gây bloat và cold-cache misses, engine ritual-audio.ts sử dụng thuần Web Audio API (AudioContext) để tổng hợp trực tiếp sóng âm chuông đồng Khâm Thiên Giám, đồng xu Càn Long, và va chạm ống tre Quan Thánh.
  • Bi-directional Cloud Sync Fallback: Dữ liệu Thư Viện Hoàng Triều hỗ trợ cả SharedPreferences/localStorage và Supabase table royal_gallery_shares, người dùng vãng lai vẫn lưu offline bình thường, người dùng VIP PRO đăng nhập sẽ tự động đồng bộ chéo tức thì.
  • Unified Toggle Pattern: Thiết kế component CeremonyAudioToggle có thể render linh hoạt ở 2 chế độ: IconButton nhỏ gọn trên AppBar hoặc FloatingActionButton trôi nổi có bóng đổ hoàng triều.

2. Deviations from Specification

  • Không phá vỡ API Contracts cũ: Thêm bảng mới royal_gallery_shares với RLS riêng và schema RoyalGalleryItemSchema trong packages/contracts, hoàn toàn không sửa đổi các schema bốc quẻ và lá số hiện hữu.
  • Svelte 5 Runes Clean Compatibility: Sửa dụng Record<string, RoyalGalleryItem> thay vì mutable Map bên trong component Svelte 5 để triệt tiêu 100% cảnh báo svelte/prefer-svelte-reactivity và tuân thủ tuyệt đối chuẩn ESLint.
