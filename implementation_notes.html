ViOS Sprint 79 Production Launch Ready Domain: tuvitoantap.online

Sprint 79: Production Launch Hardening & Custom Domain Transition

Implementation Notes, Living Spec, and Architectural Decisions as required by Karpathy Guidelines.

1. Unspecified & Implicit Decisions

  • Custom Domain Dual Alignment: Cấu hình hệ thống để hỗ trợ song song cả domain chính https://tuvitoantap.online (và https://www.tuvitoantap.online) lẫn fallback demo https://tuvitoantap.vercel.app. Đảm bảo zero-downtime khi DNS đang trong quá trình propagations.
  • Automated Sitemap Generator: Xây dựng script scripts/generate-sitemap.ts chạy trực tiếp với tsx và tích hợp vào pnpm build:sitemap cũng như hook vào build pipeline để luôn sinh mới sitemap tự động chứa 21 static routes chính và 4 dynamic blog slugs chuẩn SEO.
  • Edge CDN Cache-Control Architecture: Định nghĩa chính sách phân tầng cache trong vercel.json:
    • Static immutable assets (fonts, tarot cards, icons): public, max-age=31536000, immutable.
    • Static web metadata (manifest, favicons): public, max-age=86400, stale-while-revalidate=604800.
    • SEO search engine docs (robots.txt, sitemap.xml): public, max-age=3600, stale-while-revalidate=86400.
  • Vision AI Token Guardrail: Siết chặt quota bảo vệ token dump xuống API_VISION_REQUESTS_PER_DAY_PER_USER = 5 (thay vì 50), yêu cầu định danh email, chặn hoàn toàn anonymous bot spam.

2. Deviations from Specification

Không có sai lệch tiêu cực. Các bổ sung tối ưu hóa hiệu năng và an toàn:

  • Preconnect & DNS-Prefetch: Thêm thẻ <link rel="preconnect"> và <link rel="dns-prefetch"> cho Supabase Auth API và Cloudflare Turnstile CDN trong app.html giúp giảm 150-250ms latency cho initial load và auth handshake.
  • Vercel Domain Deployment Resilience: Trong scripts/deploy-vercel-demo.zsh, lệnh gán alias cho tuvitoantap.online được bọc với || true để quá trình deploy Vercel demo không bị ngắt quãng nếu người dùng chưa kịp verify DNS trên Dashboard.

3. Considered Trade-offs

  • Dynamic Sitemap Route vs Static Pre-generated XML:
    Phương án chọn: Sinh tĩnh apps/web/static/sitemap.xml trước khi build bằng TypeScript script.
    Lý do: 0ms serverless invocation latency, tương thích 100% với static CDN edge caching, Googlebot cào cực nhanh mà không tiêu tốn function execution compute trên Vercel.
  • Strict Host Header Checking vs Flexible Origin Fallback:
    Phương án chọn: Ưu tiên window.location.origin phía client, kết hợp fallback PUBLIC_SITE_URL || 'https://tuvitoantap.online' phía server.
    Lý do: Hoạt động trơn tru cả ở localhost:5173, Vercel preview URL (*.vercel.app) và custom domain thật (tuvitoantap.online).

4. Maintenance & Review Notes

  • Environment Variables: API_CORS_ORIGINS trong apps/api/src/config/env.ts đã bao gồm cả tuvitoantap.online và www.tuvitoantap.online.
  • Vision Hardening: Biến API_VISION_REQUESTS_PER_DAY_PER_USER điều khiển giới hạn vision toàn app, dễ dàng điều chỉnh qua env khi cần mở rộng quota.
  • Deploy Script: Luôn dùng pnpm deploy:vercel-demo để deploy demo/production chuẩn hóa.
